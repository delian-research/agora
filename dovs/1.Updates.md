# 2026-05-10 - Live security master: snapshot + append-only change log

Date: 2026-05-10
Task: Add a production-ready security master sync that produces a
       current-state snapshot and an append-only timestamped change log
       sourced from Massive's `list_tickers` and `get_ticker_events`
       APIs.

## What Changed

### New module `agora/download/security_master.py`
- Public entry point: `sync_security_master(...)` — fetches universe,
  diffs against prior master, writes new master + appends change log.
- `fetch_universe()` pulls one `list_tickers` per (market, type). Scopes:
  stocks (10 equity types), fx (USD-quoted pairs), indices (allowlist
  from `data/indices_included.csv`).
- `compute_changes()` is a pure diff producing `added` / `deactivated` /
  `reactivated` / `field_changed` rows on watched fields (`ticker`,
  `name`, `cik`, `type`, `locale`, `primary_exchange`, `currency_name`,
  `share_class_figi`).
- `backfill_rename_history()` calls `get_ticker_events` per ticker and
  emits `ticker_renamed` rows with Polygon's authoritative `event_date`.
  Cache-first via `_EventCache` (precomputed dict lookups over
  `ticker_events.parquet`).
- `merge_master()` carries `first_seen_at` from prior rows, advances
  `last_seen_at` only on rows confirmed today, marks absent rows
  `active=False` while preserving them.

### Production hardening (post-review)
- **Atomic writes**: `_atomic_write_parquet` writes to `<path>.tmp`
  then `os.replace`. Killed processes never corrupt master/changes.
- **Strict universe by default**: failed `list_tickers` segments raise
  `PartialUniverseError` instead of silently emitting thousands of
  spurious `deactivated` rows. CLI flag `--allow-partial` opts out.
- **O(1) cache**: `_EventCache` replaces per-call DataFrame scans
  (was O(N²)). Daily-sync wall time: ~270s → ~22s (12× speedup).
- **`event_date` normalization**: both cache and API paths emit
  `YYYY-MM-DD`; dedupe keys are stable across runs.

### CLI: `python -m agora.download security-master`
Flags: `--full-event-backfill`, `--no-events`, `--no-snapshot`,
`--allow-partial`. Default is incremental + cache-first.

### Outputs (`data/reference/`)
- `security_master.parquet` — current state, one row per identity
- `security_master_changes.parquet` — append-only log
- `snapshots/tickers_<YYYY-MM-DD>.parquet` — dated raw snapshots

### `agora/loaders/parquet.py` additions
- `get_security_master(active_only, market, ticker_type)`
- `get_security_master_changes(composite_figi, ticker, change_type, start, end, run_id)`
- `audit_security(composite_figi)` — full history for one identity
- `resolve_security(composite_figi, ticker, as_of)` — historical
  resolution with `ticker_events.parquet` fallback

### Configuration changes
- `REST_RATE_LIMIT` bumped from 5 → 500 calls/min (paid tier ceiling).
- `data/indices_included.csv` — editable index allowlist (318 rows by
  default: industry, style, geographic, broad, size, thematic, macro).

### Tests
- `tests/test_security_master.py` — 34 tests covering pure-functional
  diff, merge, dedupe, event normalization, `_EventCache` lookups,
  CSV-driven allowlist, atomic writes, partial-pull strict mode,
  cross-source `event_date` consistency. Total suite: 208 passing.

## Bootstrap result (verified end-to-end)
- Master: 12,216 rows (11,782 stocks + 318 indices + 116 fx)
- Change log: 23,879 rows on a single `run_id` (12,216 `added` +
  11,663 `ticker_renamed`)
- Wall time: 4.5 min on first bootstrap, 22s on incremental re-run

# 2026-04-29 - Audit polish: rename, packaging metadata, test scaffold

Date: 2026-04-29
Task: Close out the remaining "inconsistencies" from the audit
       (`dovs/a.structure.md` § 4) — file rename, pyproject metadata,
       pytest scaffold.

## Context Reviewed

- `dovs/a.structure.md` — audit inconsistencies list
- `dovs/2.Projects.md` — project plan written before doing the work
- `agora/loaders/s3.py` — misleading filename (reads Parquet, not S3)
- `pyproject.toml` — placeholder description, no build-system, no metadata
- No existing `tests/` directory

## What Changed

### Rename
- `agora/loaders/s3.py` → `agora/loaders/parquet.py` (445 LoC)
- New `agora/loaders/s3.py` (33 LoC) is a deprecation shim that
  re-exports `FlatFileLoader` from `parquet.py` and emits a
  `DeprecationWarning` on import.
- Internal references updated:
  - `agora/client.py` `flat_files()` factory
  - `agora/__init__.py` docstring
  - `AGENTS.md` (two occurrences)
  - `dovs/a.structure.md` (audit table now shows both rows)
  - `dovs/b.loaders_doc.md` (naming note updated; module-summary table
    shows both rows)

### Packaging metadata (`pyproject.toml`)
- Real description, `authors`, `license`, `keywords`, `classifiers`.
- New `[project.optional-dependencies] dev` group with `pytest` +
  `pytest-mock`.
- Added `[build-system]` with `hatchling` so `pip install -e .` works
  without ceremony.
- Added `[tool.hatch.build.targets.wheel] packages = ["agora"]`.
- Added `[tool.pytest.ini_options]` — `testpaths = ["tests"]`,
  `addopts = "-q --strict-markers"`, deprecation-warning suppression
  scoped to the s3 shim module.

### Tests scaffold (`tests/`)
- `tests/__init__.py` (empty marker).
- `tests/conftest.py` — adds repo root to `sys.path` for ad-hoc runs.
- `tests/test_imports.py` — smoke tests over 17 public modules,
  `__version__` shape, download exports, s3 deprecation warning,
  `MassiveClient` factory. Would have caught BUGs 1, 2, 4–7, 10
  immediately.
- `tests/test_loaders.py` — `FlatFileLoader` behavior, skipped
  cleanly when the local Parquet store is absent (so a fresh
  checkout isn't blocked by needing 327 MB of data).
- `tests/test_websocket.py` — channel routing, dispatch, capture
  (buffer + JSONL), validation, all with `WebSocketClient.subscribe`
  mocked so no live socket is opened.

## Why

- The `s3.py` filename actively misled — the audit flagged it. Renaming
  + a shim is a one-time cost that prevents future confusion.
- A blank `pyproject.toml` description and missing `[build-system]`
  meant `pip install -e .` failed silently in fresh envs and the
  package shipped without identifying metadata.
- Zero tests meant the audit's BUG-1..11 surface had no tripwire — the
  smoke suite is the cheapest way to add one.

## Impact

- `pip install -e .` and `uv sync --extra dev` both work.
- `pytest` finds and runs 38 tests, all passing in < 0.5s.
- The deprecation shim documents and *enforces* the migration path:
  every `from agora.loaders.s3 import …` warns once at import time, so
  callers see the path forward immediately.
- The audit's "inconsistencies" section has now been worked through —
  remaining items (`models.py` empty, `dovs/` typo for `docs/`,
  `RestApi.md` empty stub) are intentional placeholders or
  organizational choices, not defects.

# 2026-04-29 - Repository Audit Fixes + WebSocket Loader

Date: 2026-04-29
Task: Repair latent runtime bugs uncovered during audit; implement the
       WebSocket streaming loader.

## Context Reviewed

- `dovs/a.structure.md` — audit report listing 11 bugs and 17 inconsistencies
- `agora/loaders/rest.py`, `agora/client.py`, `agora/adapters/market.py`,
  `agora/normalize/{snapshot,corporate_actions}.py` — broken modules
- `agora/loaders/socket.py` — empty placeholder for streaming
- `massive` SDK source for `WebSocketClient`, `Feed`, `Market`, and
  `EventType` enums

## What Changed

### Audit fixes
- `agora/__init__.py` — populated with module docstring + `__version__ = "0.1.0"`
- `.gitignore` — added `.env`, `data/`, `.idea/`, `.DS_Store`
- `agora/normalize/snapshot.py` — `from massive_data.normalize.base` →
  `from agora.normalize.base`
- `agora/normalize/corporate_actions.py` — same fix
- `agora/loaders/rest.py` — imported `MassiveConfig`, replaced two
  undefined `get_config()` calls (decorator + `__init__`) with
  `MassiveConfig.from_env()`; instance config preferred when available;
  fixed comma-spacing in import line
- `agora/client.py` — full rewrite. Removed dead `_http_client` plumbing,
  property/attribute conflict on `rest`, undefined `_stocks` reference,
  invalid `dotenv_path` kwarg. Added `.flat_files()` and `.ws_streamer()`
  factory methods.
- `agora/adapters/market.py` — replaced non-existent `c.stocks.aggregates(...)`
  call with `c.rest.get_aggregates(...)`. Inlined `Agg` → DataFrame
  construction. Fixed `from massive_data import …` docstrings to
  `from agora.adapters.market import …`.
- `agora/download/__init__.py` — added `download_ticker_events` to public
  exports (was used by CLI but not re-exported).

### WebSocket loader
- `agora/loaders/socket.py` — implemented `WebSocketStreamer`:
  - Per-market construction (`stocks` / `forex` / `crypto` / `indices`),
    routed via `_CHANNEL_CODES` table so verbs like `subscribe_trades`
    map to `T` for stocks, `XT` for crypto, etc.
  - High-level subscribe verbs: `subscribe_trades`, `subscribe_quotes`,
    `subscribe_minute_aggs`, `subscribe_second_aggs`, `subscribe_values`,
    `subscribe_luld`, `subscribe_imbalances`, `subscribe_l2_book`,
    `subscribe_raw` (escape hatch).
  - Slash-notation auto-normalization for forex/crypto pairs
    (`"EUR/USD"` → `"C:EURUSD"`).
  - Decorator-based handler registry with optional `events` filter.
  - Capture helpers: in-memory `buffer(maxlen=N)` and append-mode JSONL
    sink via `dump_to_jsonl(path)`.
  - Optional `run(timeout=N)` using a `threading.Timer` that calls
    `_thread.interrupt_main()` so `KeyboardInterrupt` propagates through
    `asyncio.run`.
  - Defaults to `Feed.Delayed` since real-time WS is not included with
    Stocks Starter; users can pass `feed=Feed.RealTime` if entitled.
  - Async-`close()` quirk handled: detects coroutine return from the SDK
    and `.close()`-s the coroutine object to avoid the
    `RuntimeWarning: coroutine ... was never awaited`.

### Documentation
- `dovs/b.loaders_doc.md` — comprehensive loaders documentation covering
  all three retrieval modes (REST, Parquet, WebSocket), with decision
  matrix, method index, and plan/runtime gotchas.

## Why

- The audit found that 4 modules in the older "live API" stack were broken
  at import or first-call (wrong package names, undefined identifiers,
  non-existent attribute paths). The download pipeline was unaffected
  because it bypassed those modules.
- WebSocket streaming was a blank placeholder; needed for live-data use
  cases (snapshot complement to flat files).
- A consolidated loaders doc was needed because the README and AGENTS.md
  documented overlapping but slightly inconsistent architectures.

## Impact

- Every module in `agora/` now imports cleanly (verified via
  `importlib.import_module` smoke).
- `agora.client.MassiveClient.from_env()` works; `.rest`, `.flat_files()`,
  `.ws_streamer()` all return functioning sub-clients.
- `agora.adapters.market.get_prices(["AAPL","MSFT"], …)` returns real
  OHLC matrices (verified live).
- `WebSocketStreamer` connects, authenticates, subscribes, dispatches,
  and shuts down cleanly with no `RuntimeWarning`.
- `.env` and `data/` are now gitignored — credentials and 327 MB of
  generated Parquet won't accidentally be committed.

## Examples or References

- Commands/tests/checks run:
  - `importlib.import_module(m)` across 12 modules — all OK
  - `MassiveClient.from_env()` followed by `.rest`, `.flat_files()`,
    `.ws_streamer()` instantiation
  - `get_prices(["AAPL","MSFT"], start="2025-01-01", end="2025-01-15")`
    returned (9, 2) DataFrame with real prices
  - `get_returns(["AAPL"], period="1mo")` returned (20, 1) DataFrame
  - WebSocketStreamer 10-test structural suite (subscriptions, handler
    routing, buffer, JSONL sink, error rejection) — all passed
  - Live WS connection test (4s window): auth + sub + clean close, no
    RuntimeWarning under `python -W error::RuntimeWarning`
- Outcome: All previously-broken paths now functional.
