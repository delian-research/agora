### 2026-04-29 Audit polish: rename, packaging metadata, test scaffold

- Close out the remaining "inconsistencies" from `dovs/a.structure.md` after
  the BUG-1..11 runtime fixes shipped earlier today. These items are
  cosmetic / packaging / hygiene, not blocking, but worth doing now while
  the audit is fresh.

### Goal

- Make `agora/loaders/s3.py` filename match its actual behavior
  (it reads local Parquet, not S3) by renaming to `loaders/parquet.py`,
  with a back-compat alias so existing import sites still work.
- Replace `pyproject.toml` placeholder description and add minimal
  package metadata (authors, license classifier).
- Establish a `tests/` directory with a small pytest smoke suite that
  exercises the import-graph + the public APIs that historically broke
  silently (the audit's BUG-1..11 surface).

### Scope

- **In**: file rename + import updates, `pyproject.toml` metadata,
  `tests/` scaffold (~3 test files), an entry in `1.Updates.md`.
- **Out**: deeper test coverage (we'll seed the structure but not chase
  coverage); doc folder rename `dovs/` → `docs/` (separate concern);
  populating `agora/models.py` (premature — Pydantic models are still
  being designed); fleshing out `loaders/socket.py` further.

### Architecture / Plan

1. **Rename `s3.py` → `parquet.py`**
   - `mv agora/loaders/s3.py agora/loaders/parquet.py`
   - Update internal imports: `agora/client.py`, `agora/__init__.py`,
     and anything else importing `agora.loaders.s3`.
   - Add a tiny `agora/loaders/s3.py` shim that re-exports from
     `parquet.py` and emits a `DeprecationWarning` on import — that way
     any external caller (or doc snippet) using the old name keeps working.
   - Update `dovs/b.loaders_doc.md` "naming note" since the historical
     reason no longer applies.

2. **`pyproject.toml` cleanup**
   - Replace `description = "Add your description here"` with a real
     one-liner.
   - Add `authors`, `license`, and a couple of standard classifiers.
   - Pin `[build-system]` so the package is installable in a fresh env
     (`uv` works without it but `pip install -e .` complains).

3. **`tests/` scaffold**
   - `tests/__init__.py` (empty marker)
   - `tests/test_imports.py` — smoke test that imports every module in
     the public surface (would have caught BUGs 1, 2, 4, 6, 8 immediately).
   - `tests/test_loaders.py` — basic FlatFileLoader behavior against
     `data/` if present, skipped otherwise (avoids requiring the 327 MB
     Parquet store on dev machines that haven't run the downloader).
   - `tests/test_websocket.py` — structural tests for `WebSocketStreamer`
     that mock `WebSocketClient.subscribe` (so no live connection needed).
   - Add `[tool.pytest.ini_options]` to `pyproject.toml` so `pytest`
     picks up the directory and uses sensible defaults.

### Risks

- **Rename breaking external code**: mitigated by the deprecation shim.
- **Tests requiring live API key**: kept out of the smoke suite — the
  three test files only need pure-Python imports, local Parquet (which
  may or may not be present, and is skipped when absent), and mocks for
  WebSocket. CI without secrets would still pass.
- **`pyproject.toml` build-system change** could break `uv sync` if not
  done carefully — verify with a fresh `uv sync` after the change.

### Verification

- `python -c "import agora.loaders.s3; import agora.loaders.parquet"` —
  both work, the first emits a DeprecationWarning.
- Full import sweep across all 14 public modules (as in the audit-fix
  session).
- `uv run pytest -q` shows the smoke tests passing locally.
- `pip install -e .` installs cleanly.
